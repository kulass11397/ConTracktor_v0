ConTracktor_v1 1.5.0 — INVENTORY AND OPERATIONS UPDATE
======================================================

WHAT TO SEND
------------
Send only this file to the client:
  ConTracktor_v1_Setup_1.5.0_Inventory.exe

SAFE UPDATE STEPS
-----------------
1. Close ConTracktor completely.
2. Keep the client computer connected to power during the update.
3. Double-click the installer and approve the update.
4. Wait for the success message. ConTracktor opens automatically.
5. Confirm that the existing projects and records are still visible.
6. Open Inventory and select a project to begin registering stock and tools.

DATA SAFEGUARDS
---------------
- This update does not contain or replace contractor_tracker.db.
- Before updating files, it backs up the active database and SQLite sidecars to:
  %LOCALAPPDATA%\ConTracktor_v1\Data\Backups\Before_v1.5.0_<timestamp>\
- It also backs up the previously installed application files to:
  %LOCALAPPDATA%\ConTracktor_v1\AppBackups\Before_v1.5.0_<timestamp>\
- Inventory tables are added to the existing database on first launch.
- Existing expenses, payroll, remittances, employees and projects remain in place.

NEW INVENTORY WORKFLOW
----------------------
- Register consumable materials or non-consumable tools per project.
- Record consumable restocks and employee usage with reasons.
- Borrow tools under an active employee's name and return against the same borrowing record.
- View stock, complete activity history and active borrowers.
- Completed projects retain a read-only inventory history in their closeout record.
